## Состав
- index.html — главная; investors.html — страница для инвесторов; studio-privacy.html — политика конфиденциальности служебного приложения (закрыта от индексации)

- video/ — ролик ii-analitik-demo-b.mp4 и обложка poster-b.jpg (используются на главной)
- sitemap.xml, robots.txt — для поисковиков; googlee6e820168b7b4521.html и yandex_71dee22103e2923c.html — подтверждения Google и Яндекса, не удалять
