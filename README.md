# ИИ-аналитик для 1С — сайт

Статический сайт, сборка не нужна. Открывается index.html.

Публикация: GitHub Pages, ветка main, корень репозитория, домен ii-analitik.site (файл CNAME).

## Состав
- index.html — главная (раздел «ИИ-аналитик»); modules/index.html — «Модули 1С»; investors/index.html — «Инвесторам» (закрыта от индексации тегом noindex). Три отдельные страницы с общими шапкой и подвалом: при смене шапки или подвала правьте все три. uslugi.html и investors.html — переходы на /modules/ и /investors/; старые ссылки вида /#/modules site.js тоже переводит на новые адреса; site.js — плашка cookie, Метрика после «Понятно», стрелка «наверх»; cookies.html — политика cookies; studio-privacy.html — политика конфиденциальности служебного приложения (закрыта от индексации)
- styles.css — общие стили
- video/ — ролики и обложки для главной: ii-analitik-demo-b.mp4 и poster-b.jpg («Бот за работой», запись 27.10); ii-analitik-express.mp4 и poster-express.jpg (режим «Экспресс»)
- sitemap.xml, robots.txt — для поисковиков; googlee6e820168b7b4521.html и yandex_71dee22103e2923c.html — подтверждения Google и Яндекса, не удалять

## Правила
- Окончания строк в репозитории — LF.
- Контакты (Telegram @egorka_vin, телефон, e-mail, канал t.me/ii_analitik_1c) совпадают на всех страницах.
- На публичных страницах нет цен и сумм; сроки пилота — «ориентировочно ноябрь 2026».
- После правки страниц обновляйте lastmod в sitemap.xml (в нём главная и /modules/; /investors/ закрыта от индексации и в sitemap не входит).
- На публичных страницах нет цен, названий конкурентов, конкретных банков и операторов касс; модули описываем словами «разрабатываем», «планируем», «пилот».
- Ничего не писать про обработку и передачу данных (в том числе «данные никуда не передаются») без слова владельца: юридическая проверка не закончена.
- Название юрлица на сайте не писать, пока юрлицо не открыто.
